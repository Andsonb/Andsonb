## 👨‍💻 Sobre mim

Sou **Especialista de Sistemas** no varejo, com origem em **redes e segurança**. Hoje junto as duas pontas: mantenho a infraestrutura de uma rede distribuída com **70+ lojas, matriz e centros de distribuição**, e desenvolvo as ferramentas que a monitoram. Não só opero: **projetei e implantei** a base de rede, monitoramento e segurança.

### 🏗️ O que eu construí

- 🔥 **Parque Fortinet completo:** configurei os **70+ FortiGates** da rede: SD-WAN, VPN IPsec Hub-and-Spoke, BGP e redundância de links em todas as lojas
- 📡 **Servidor Zabbix corporativo:** implantei do zero o monitoramento central de firewalls, links e serviços, com dashboards no Grafana
- 🛡️ **SIEM Wazuh:** implantei a centralização de eventos de segurança de lojas e servidores
- 🖥️ **Plataforma de NOC própria:** desenvolvi o painel que mostra o status de cada loja em tempo real, com alertas via WhatsApp

### ⚙️ O que eu sustento

- 🌐 **Toda a infraestrutura de redes:** firewalls, switches, Wi-Fi, links e VPNs de lojas, matriz e CDs
- 🧩 **Sistemas críticos:** sustentação de ERP e WMS, monitoramento de jobs Oracle, Active Directory e GPO
- 🎓 Graduado em **Redes de Computadores** · Pós-graduado em **Segurança de Redes**

> *"Se não está monitorado, não está em produção."*

## 🚀 Projeto em destaque: plataforma de NOC para varejo

Plataforma web que centraliza o monitoramento de lojas: status de **WAN1/WAN2, satélite e VPNs**, incidentes, relatórios e **notificações via WhatsApp**, usando o Zabbix como fonte de dados (somente leitura).

| Camada | Tecnologia |
|---|---|
| Frontend | Next.js · TypeScript |
| Backend | FastAPI · Python · workers assíncronos |
| Dados | PostgreSQL como cache persistente |
| Integrações | Zabbix API · Oracle (Scheduler Jobs) · WhatsApp (Meta Cloud API / Evolution API) |
| Deploy | Docker Compose |

**Destaques de engenharia:** controle de acesso por perfil (o TI da loja só vê a própria loja), segredos só no backend, nenhum dado inventado (UNKNOWN ≠ DOWN), outbox de notificações com retentativas e isolamento de falhas.
